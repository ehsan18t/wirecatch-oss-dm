# Contract 30: protocol-types

Plain types and small pure functions from `crates/protocol`: `app`, `desktop`, `exported`, `languages`, `media_start`. No I/O, no state.

## `MediaDefaults::start(options, subtitles, chapters) -> MediaStart`

- The one rule for where a quality window starts and whether it opens (D50.4). `options` must be best first; core calls it in `manager/media.rs`.
- `asks` is `ask_each_time`, or a missing saved quality with fallback `Ask`. Core also opens the window when the start cannot be resolved or needs ffmpeg that is absent.
- `missing` is `"{h}p"`, or `"Audio only"` when audio only is saved and not offered. A video with no stated heights, or audio alone, starts on option 0 with nothing missing.
- Fallback: `Lower` and `Ask` take the closest lower, else the lowest; `Higher` the closest higher, else the best. Ties among equal heights take the last listed for a maximum: safe only because `crates/media` offers one option per height.
- The saved format falls back to `Original` when the option does not offer it. `audio_kbps` is the offered rate nearest the saved one, else `None` when the audio is not re-encoded, else the format's default. Always a value of `kbps_choices`.
- `chapters` is the video's and the saved flag together; it does not check the format can hold them (`Plan::resolve` does).
- With no options: an empty `option_id` and the default output.
- `preselected_subtitles`: per saved language, the first written by people, else the first auto one when `auto`, each id once. A language matches exactly or by its primary tag, ignoring case (`en-GB` matches `en`, `pt` does not match `pt-br`).

## Settings and patches

- `AppSettings::apply`, `MediaDefaults::apply`, `OutputDefaults::apply` name every field on both sides, so a new field must be handled to compile.
- Patches have `deny_unknown_fields`. `Update<T>`: missing is `Keep`, any value including `null` is `Set`; other patch fields read `null` as unchanged. Keep `skip_serializing_if = "Update::is_keep"` on every `Update` field.
- `known_or_default` (theme, accent, clock, notify and notice times, `when_file_exists`, `quality`, `fallback`, `unembedded_subtitles`, queue `notify`): an unknown stored value reads as the default. `OutputFormat`, `Category` and most other enums have no such tolerance: an unknown value fails the whole read.
- Fresh-install defaults for `AppSettings` live in `crates/settings`, not here. `MediaDefaults::default` has `ask_each_time: true`.
- `AddonId` reads any unknown name as `Unknown`, which writes back as `"unknown"`.

## Limits and tables

- `MAX_CONNECTIONS_PER_DOWNLOAD` 32 (default 8), `MAX_CONCURRENT_DOWNLOADS` 100 (default 5), `MAX_QUEUE_DESCRIPTION_CHARS` 500, `PER_MILLE_DONE` 1000, `SETTINGS_FILE_FORMAT_VERSION` 3, `MAX_QUESTION_WINDOWS` 5, `MAX_FINISHED_LISTED` 100, `MAX_FINISHED_GROUPS` 20. These are declared; `crates/settings` and `crates/shell` enforce them.
- `OutputFormat`: `saves_video`, `saves_audio`, `is_lossless`, `kbps_choices`, `default_kbps`; only `Original` saves both. `default_kbps` is always one of `kbps_choices`.
- `SAFE_EXTENSIONS`: lower-case allowlist of files that open without asking; `crates/shell::api::is_program` applies it.
- `RETRY_FIXES`: `Retry` and `FreeDiskSpace`; only `crates/shell/src/notifications.rs` honours it.
- `LANGUAGES`: sorted by code, each code once; names are not unique.

## Questions and events

- `QuestionId` is one id space across `Capture`, `Reading`, `Choice`, `Addon` and `FileExists`; a question keeps its id between steps, and `Question::id` reads it.
- `UiEvent` variants without a product reader: `SettingsImported`, `SuffixListChecked`.
- `Reveal`: `browser_settings` and `proxy_settings` win over the rest; `details` is ignored by `MainWindow::reveal`.

## Generation

- `exported_consts!` declares ordinary constants and, under `cfg(test)`, a list for the generator; a module using it must also be listed in `write_typescript_constants`.
- Whole numbers beyond 2^53 - 1 panic the generator rather than being written wrong. `constants.ts` and `fixtures.json` are written by tests, into `TS_RS_EXPORT_DIR`.
