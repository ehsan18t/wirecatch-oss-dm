# Contract 10: site-rules

`crates/sites` and `crates/core/src/manager/suffix_list.rs`, as the code behaves.

## `public_suffix::SuffixList`

- `built_in()`: the snapshot, read once per process. An unreadable snapshot gives an empty list dated 0, never a panic.
- `load(dir, now)`: blocks on the disk. The kept `public-suffix-list.dat` when `accept` takes it against the built-in list at `now` and it is newer than the built-in list; otherwise the built-in list. Never fails.
- `accept(bytes, current, now)`: at most 2 MiB, UTF-8, four section markers in order, a `VERSION` line in the leading comments, every rule readable, at least 9/10 of `current`'s rules and of its ICANN rules, at most twice its rules, dated at most a day after `now`. It does not check that the list is newer: the caller does.
- `registrable_domain(name)`: a slice of `name`, or `None` at or above a public suffix. An unknown last label is a suffix of its own (implicit `*`). `name` must be lower case, ASCII, with no trailing dot; callers trim the dot.
- `is_public_suffix(name)`: true only when a rule ends exactly at `name`. False for a top-level domain held only through a wildcard (`jm`, `ck`), see 10-2.

## `cookie_scope`

- `site_of`: `scheme://registrable-domain` for http and https only, else `None`. An IP address, a host with an empty label or a public suffix is its own site. One or more trailing dots are dropped; the port is ignored.
- `is_cross_site`: true unless the initiator is present and same-site with the target, and `original_url` and `top_level`, when present, are same-site too. A missing or unreadable initiator is cross-site.
- `cookie_header(jar, url, suffixes)`: same-site sends all; cross-site never `Strict`, `Lax` and `Unspecified` only when `navigation`, always `NoRestriction`. `None` when none goes. Cookie order is the jar's. Values are not checked.

## `local_network`

- `ChosenBy` is `Person`, `LocalPage` or `Website`, stored with a download. `private_network()` is the one mapping: `Auto` for the first two, `Block` for `Website`.
- `of_capture` makes no lookup. `LocalPage` needs at least one page address, every one local or listed, and a frame trace unless the source is `BrowserDownload`. It does not check the address's scheme (10-1).
- `is_local_by_itself`: by the engine's `AddressKind` for an address; otherwise a dotless name that is not a public suffix, or a name under `LOCAL_SUFFIXES`, or `lan` while unlisted.
- `is_on_own_network`: the above, or under a listed site that is still registrable by the list passed in.
- `local_site(entry, suffixes)`: `Ok(None)` for white space; the normalized host when registrable; `Err` for `Unreadable`, `Address` or `Shared`.
- `refuses`: only ever true for `Website`: its host is a local address, or a name with at least one answer, all local, within 3 seconds. No answer or a timeout is false, and the engine decides. `refuses_address` is the same without a lookup. Neither lets anything through: `Block` still applies at the connection.
- `addresses(url, timeout)`: empty on failure or timeout.

## `video_sites::video_site_for`

http and https only. The first listed site whose host and path match gives its name; otherwise an added site gives its normalized host, for any path but the home page. Used by the add dialog; the list and cases are JSON shared with the extension. A host with a trailing dot does not match.

## `Manager` (`suffix_list.rs`)

- `suffix_list()`: `SuffixListInfo` without waiting on the network.
- `check_suffix_list()`: runs whatever the setting says, one at a time. Fails with `UpdateCheckFailed` when no source is configured (no event then), or when the fetch, the checks or the save fail, keeping the list in use. Every check that ran saves its record and emits `UiEvent::SuffixListChecked`, unless the manager closed.
- A list is on disk before it is used. A newer list in use drops stored `local_sites` it makes public, through `apply_settings`, so settings stay valid and windows hear of it.
- Weekly check: looked for hourly, first an hour after opening; needs a source, the setting on and no running download; due a week after a current check, a day after a failed one, at once after one recorded ahead of the clock, and before any check once the list in use is a week old.
- A manager fetches only when its configuration names a source. Only the desktop app names the official one.
- `SuffixList` lives in manager state: read it fresh under the lock; a decision already stored (`chosen_by`) does not change when the list does.
